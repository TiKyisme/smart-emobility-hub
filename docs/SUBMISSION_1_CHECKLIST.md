# Submission #1 Checklist

## Required content

- [ ] Project context is described.
- [ ] Relevant stakeholders, roles, and expectations are identified.
- [ ] Project objectives are stated.
- [ ] Project scope/boundaries are stated.
- [ ] Functional requirements are included.
- [ ] Whole-system Use Case Diagram is included as a visible image in the PDF.
- [ ] Each member has their own detailed use-case scenario.
- [ ] General non-functional requirements are included.
- [ ] `[TEAM_DECISION]` placeholders are resolved.

## Consistency checks

- [ ] Actor names match between report and Use Case Diagram.
- [ ] Use case names/IDs match between diagram and scenarios.
- [ ] Functional requirements do not contain invented features.
- [ ] Use-case scenarios agree with requirements.
- [ ] Diagram symbols/names/relationships can be explained by the team.

## Submission checks

- [ ] Export one PDF.
- [ ] File name is `YourClass_GroupNo.pdf` (example `L03_1.pdf`).
- [ ] Diagrams are readable at normal zoom.
- [ ] No diagram link is used as a substitute for the embedded diagram.
- [ ] Only the group leader submits.
